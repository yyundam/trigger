잊지마 (할일 알람 앱) — 설치 방법

[1] GitHub에 올리기 (처음 한 번)
  1. github.com 에서 New repository → 이름 trigger → Public → Create
  2. "uploading an existing file" 클릭
  3. 이 폴더 안의 내용 중 "빌드설정_build.yml" 만 빼고 전부(app 폴더 + 파일들) 끌어다 놓기 → Commit changes
  4. 저장소 첫 화면에서 Add file → Create new file
     파일 이름 칸에 정확히:  .github/workflows/build.yml
     내용 칸에 "빌드설정_build.yml" 내용을 메모장으로 열어 전부 복사·붙여넣기 → Commit changes
  5. 위쪽 Actions 탭 → 빌드가 자동 시작 (약 5분) → 초록 체크 뜨면 완료

[2] 폰에 설치
  1. 폰에서 https://github.com/yyundam/trigger/releases/latest/download/trigger.apk 누르기
  2. 받은 trigger.apk 열기 → "출처를 알 수 없는 앱 설치 허용" → 설치
  3. 앱을 처음 열면 알림 허용. 화면 위에 빨간 줄이 뜨면 눌러서 허용

[3] 갤럭시라면 꼭
  설정 → 애플리케이션 → 잊지마 → 배터리 → "제한 없음"
  (안 하면 절전 때문에 알람이 늦거나 안 울릴 수 있어요)

[수정할 때]
  코드 파일을 고쳐서 GitHub에 다시 올리면 새 apk가 자동으로 만들어지고,
  폰에서 받아 설치하면 기존 알람은 유지된 채 업데이트돼요.

[사용법]
  ① 언제 알려드릴까요? → 날짜 박스에서 날짜 → 시각 박스가 밝아지면 시각 누르기
     (원하는 시각이 없으면 ＋다른시각 → 큰 화면에서 고르기. 자주 쓰는 시각은 자동으로 바뀌어요)
  ② 그때 무엇을 알려드릴까요? → 🎙 말로 하기 또는 ⌨ 글자로 쓰기
     말로 하기: 처음 한 번 마이크 허용. 말하고 3초 쉬면 자동으로 넘어가요. 맞으면 [✓ 확인]
     글자로 쓰기: 적고 [✓ 확인]
  저장되면 5초 동안 크게 보여주고 소리로 읽어줘요.
  알람이 울리면 적어둔 내용을 크게 보여주고 읽어줘요.
  첫 화면 오른쪽 위 "예정" → 맞춰둔 알림 목록, 누르면 삭제
